# Лабораторная работа - Вариант 8

## Задача
В списке выбрать все элементы, которые встречаются более одного раза, без повторения.

## Описание
Android приложение на Kotlin для поиска дубликатов в списке.

## Файлы
- `MainActivity.kt` - основной код
- `ListFunctions.kt` - функции обработки и генерации списка
